## 🌟 项目立意与解决的痛点

在传统的计算机专业学习与全国硕士研究生统一入学考试（408 计算机学科专业基础）备考中，学习者普遍面临**“三大深水区痛点”**：

1. **底层过程抽象隐蔽，传统教材沦为“死记硬背”**：
   * CPU 五级流水线中的数据冒险（RAW）、前递技术与气泡停顿在书本上只是静态的几张图；
   * Cache 组相联映射与循环颠簸（Thrashing）缺少物理时钟下的逐次命中验证；
   * 操作系统进程并发互斥、死锁资源分配图化简与银行家算法安全序列推导枯燥抽象。
2. **刷题与底层实验割裂脱节**：
   * 历年统考真题考法极其深入底层，学生做错题目后往往只能查看文字版答案解析，无法一键复现题目中的计算机硬件时序状态。
3. **学情盲区难以数字化量化追踪**：
   * 缺乏针对 408 四大学科（计组、操作系统、计网、数据结构）的雷达图能力画像与针对目标院校的专属研学方案。

**CSCOPE (Computer Microscopic Architecture & Simulation Scope)** 由此诞生！平台以**“微观物理时钟级仿真沙盒”**为基石，向上贯通**“105 道历年 408 统考真题库”**、**“DeepSeek-R1 计算机私教大模型”**与**“终身学情画像系统”**，彻底让抽象的底层计算过程变得看得见、摸得着、能推演！

### 1. 25 个底层时钟微观交互仿真沙盒
涵盖 408 统考与核心计算机系统课的 6 大领域：
* **计算机组成原理**：
  * **CPU 五级流水线与冒险推演**：支持指令单步打拍时钟推进，直观观察 IF、ID、EX、MEM、WB 重叠执行，精确观测 RAW 数据冒险、前递机制（Forwarding）、停顿插入（Stall Bubble）与分支预测冲刷。
  * **Cache 组相联映射与命中实验**：地址位自动拆分（Tag / Set Index / Offset），支持直接映射、全相联与多路组相联对比，动态验证 Cache 循环颠簸导致 100% 缺失率的物理本质。
  * **指令执行周期数据通路**：PC、MAR、MDR、IR、ACC 在取指、译码、执行、写回中的总线微操作流转。
  * **补码运算与 IEEE 754 浮点数**：阶码移码、尾数规格化与舍入溢出深度拆解。
* **操作系统内核**：
  * **死锁：预防、避免与银行家算法**：透视死锁四个必要条件，动态录入 Max / Allocation / Need 矩阵，推导安全序列，交互式化简资源分配图（RAG）。
  * **进程五状态模型与 CPU 调度**：创建、就绪、运行、阻塞、终止动态流转，PCB 上下文切换，对比 FCFS、SJF、时间片轮转（RR）甘特图。
  * **虚拟内存页面置换**：FIFO、LRU 与最佳置换（OPT）缺页中断、淘汰策略实时对比。
  * **进程同步与互斥**：经典生产者-消费者模型，信号量 P/V 操作与互斥锁临界区可视化。
  * **动态内存分区分配**：首次适应、循环首次适应、最佳适应与最坏适应算法及碎片紧凑。
* **计算机网络协议栈**：
  * **TCP 三次握手与四次挥手**：全真 TCP 状态机（LISTEN -> SYN_SENT -> ESTABLISHED -> FIN_WAIT_1 -> TIME_WAIT -> CLOSED），逐包观察 SEQ / ACK 变化与 2MSL 等待物理意义。
  * **滑动窗口与拥塞控制**：慢启动、拥塞避免、快重传与快恢复动态折线图。
  * **IP 地址与 CIDR 子网划分**：动态拖拽掩码前缀边界，毫秒级推导网络地址、广播地址与有效主机号范围。
  * **DNS 域名解析全流程**：根域名、顶级域名、权威域名递归与迭代查询模拟。
* **数据结构与算法**：
  * **Dijkstra 最短路径**：候选节点集合、距离松弛（Relaxation）与前驱节点推导。
  * **二叉平衡树与树遍历**：前中后序、层序遍历与平衡旋转（LL、RR、LR、RL）过程。
  * **四大典型排序算法同屏对比**：快排、归并、堆排、冒泡的交换与比较次数统计。
* **前沿人工智能与数据库系统**：
  * **Transformer 多头注意力计算**：真实 Q/K/V 矩阵点乘、缩放、Softmax 与注意力权重热力图。
  * **B+ 树索引**：键值插入、节点分裂与叶节点双向链表范围扫描。

### 2. 105 道 408 统考全真题库 & 错题一键唤醒实验沙盘

* **错题靶向推荐消灭**：内置考点推荐算法，错题进入“靶向错题本”，通过实验验证后方可标为已掌握。

## 📦 快速安装与本地部署

### 方式一：Windows 一键快速启动（推荐）

1. 克隆本项目仓库：
   ```bash
   git clone https://github.com/CXT-02/CScope.git
   cd CScope
   ```
2. 双击运行根目录下的 **`一键启动.cmd`** 脚本；
3. 脚本会自动检查环境并在后台并发拉起服务，自动在默认浏览器中打开：
   ```
   http://127.0.0.1:5173/
   ```
4. 退出时双击 **`一键停止.cmd`** 即可安全释放所有服务端口。

---

### 方式二：手动分步启动

#### 1. 前端启动 (Frontend)
```bash
cd frontend
npm install
npm run dev
```
前端默认运行在 `http://localhost:5173`。

#### 2. 后端服务启动 (Backend - 可选增强层)
```bash
cd backend
python -m venv .venv
# Windows 激活虚拟环境
.venv\Scripts\activate
# Linux/macOS 激活虚拟环境
source .venv/bin/activate

pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

### 2. 环境变量模板与配置说明
项目根目录下提供了标准环境变量模板文件 [`.env.example`](./.env.example)。  
通常情况下，**无需做任何修改即可直接启动**；如需接入真实外部大模型，可在该文件中填入自定义配置：
```bash
# 前端服务配置
VITE_API_BASE=http://127.0.0.1:8000
VITE_PORT=5173

# 后端微服务配置
HOST=127.0.0.1
PORT=8000

# [可选] 外部大模型 API Key（留空则自动启用系统内置的 408 离线精编知识图谱）
DEEPSEEK_API_KEY=
```

3. **高健壮可复现性（无缝降级）**：独创三级降级链路，即使在评审环境断网或无 API Key 场景下，前端仿真逻辑百分之百自洽流畅运行，得分稳定。
4. **全端审美与极客工匠精神**：极致考究的居中大画幅首页、平滑跳转登录态、圆角头像保护与四大现代主题设计，兼具学术严谨与工业级软件质感。
