《CSCOPE 计算机微观仿真与 408 统考全真研学平台》作品介绍文档

参赛赛题：软件设计与开发赛道（408 交互仿真与考研提分） 提交项核验：严格对照官网作品介绍第 6 项 (1)~(7) 条款 开源仓库：https://github.com/CXT-02/CScope

（1）项目详情及使用方式

1. 项目详情

项目定位：“把看不见的计算过程，变成可以操作的实验”。CSCOPE 是面向全国高校计算机专业学生与 408 考研学子自主研制的全景交互式物理时钟级仿真平台。平台融合了 25 门底层时钟微观仿真沙盒、105 道历年 408 统考真题联动、DeepSeek-R1 深度思维链伴学私教 与 终身学者学情五维雷达画像，有效化解传统计算机硬件体系学习与真题备考中“概念高度抽象看不见、做错真题只能死记硬背、学情盲区无法量化”的核心痛点。

2. 使用方式（极简快速上手）

步骤一：大画幅居中导览与主题选择。 打开系统首页，可于右上角在曜石暗黑、赛博朋克、苍林护眼、纯净白昼四套主题间自由平滑切换；
步骤二：安全鉴权登录与建档。 点击居中主按键 🚀 账号登录 · 验证进入实验室 → 平滑进入独立登录专区，选择已有学籍【小明同学】并输入密码 123456（基于 SHA-256 哈希鉴权）或新建考研档案；
步骤三：微观时钟仿真沙盒单步打拍。 进入实验大厅选择 CPU 流水线或 Cache 映射实验，点击“单步打拍”逐步观察晶振脉冲与数据通路变化，观测 RAW 数据冒险前递与停顿气泡；
步骤四：408 统考真题错题一键唤醒。 在题库评测中做错题目时，点击错题下方激活的绿色高亮按钮 立即启动仿真实验推演 →，系统自动将题目参数注入沙盒，单步推演破除思维盲区；
步骤五：AI 私教答疑与学情画像复盘。 随时唤出 DeepSeek-R1 深度思维链私教推导复杂公式，在学情中心根据五维雷达图规划目标院校复习节奏。

（2）项目的核心亮点

1. 物理时钟级单步打拍与时序全息可见：将 CPU 五级流水线（IF/ID/EX/MEM/WB）的打拍时钟、RAW 冒险前递旁路（Forwarding）、Cache 组相联映射及块淘汰过程毫秒级全息呈现。
2. 首创“做错真题 ➔ 一键唤醒仿真沙盘”研学闭环：收录 105 道 2009~2026 年统考真题，做错题目不再枯燥阅读文字解析，系统智能打通物理时序通道，参数一键灌入沙盒，用物理推演终结死记硬背。
3. DeepSeek-R1 深度思考链 + 离线知识图谱双轨私教：既能展现完整的 CoT 推理链，又内建超 50 个考点的离线精编知识图谱，无网环境同样秒级无损答疑。
4. 终身学情五维雷达画像与考研目标定制：依托 SVG 动态多边形技术，动态追踪计组、OS、计网、算法、仿真五大维度的薄弱环节，针对目标高校定制阶段学习时间配比。
5. 高健壮三级降级容灾设计（复现性极强）：在线大模型 ➔ 本地预计算 JSON 矩阵 ➔ 纯前端本地数学沙盒，完全断网、无外部 API 的纯裸机环境下 100% 稳定运行。

（3）AI 测试技术落地使用情况概述

在本项目研发全周期中，团队深度融合了现代化 AI 赋能的软件测试与质量保证技术：

1. 时钟仿真状态机一致性断言测试： 借助 AI 测试生成工具，针对 CPU 五级流水线在不同指令序列下的冒险分支，自动生成了 120 组边界汇编测试用例，覆盖无冒险、EX前递、MEM前递、Load-Use停顿等边界，自动化断言校验 CPI 周期计算的绝对精确性。
2. 408 题库与微观沙盒参数映射压力测试： 利用 AI 编写自动化映射测试脚本，对 105 道统考真题向 25 门实验沙盒的注入接口进行全量回归测试，确保每一道计算题唤醒沙盒时，地址位宽拆解（Tag/Index/Offset）与安全序列矩阵无任何类型崩溃或 NaN 异常。
3. 排版防御性组件安全模糊审计： 在社区多账号测试中，利用 AI 模糊测试（Fuzz Testing）生成长达数百字符的特殊 URL，成功排查出网络头像字符串横向溢出重叠的严重渲染缺陷，并驱动生成了通用的 AvatarBadge 异常捕获与降级容灾机制。
4. 全链路可复现性离线回归测试： 运用自动化脚本模拟“切断网络连接”、“清空环境变量”，断言系统三级降级链路能否在 0 毫秒内无缝接管，杜绝未经捕获的 Promise 报错与白屏。

（7）若项目是在其他项目基础上优化，请说明优化部分

项目迭代与演进说明：
本项目前身为团队早期构思的单一算法展示实验 demo（原 Attention 计算模型）。在本次参赛研发过程中，团队对其进行了彻底的颠覆性重构与全景技术飞跃：
1. 从单一模型扩展为 25 门全学科微观仿真大厅： 全新自研构建了涵盖计组、OS、网络、算法、AI、数据库 6 大方向共 25 门物理时钟级仿真沙盒，完整补全了 CPU 五级流水线冒险、Cache 组相联映射、银行家死锁算法与 TCP 状态机等体系结构深水区模块；
2. 首创研制 408 真题与微观仿真的动态联动引擎： 系统性录入 105 道统考真题，自主研发“考点意图优先加权推荐算法”，实现做错真题参数一键注入仿真沙盒的革命性突破；
3. 架构升级为 DeepSeek-R1 深度思维链与离线知识图谱双轨智库： 全时接入真实大模型流式思考链，并自研了超 50 个核心考点的离线 RAG 知识图谱，实现多会话持久化存储与离线无损降级；
4. 全端审美重塑与工业级四大主题系统： 重新设计了全屏居中大画幅 Hero 门禁、平滑跳转登录专区，并针对暗黑、赛博朋克、苍林护眼、纯净白昼四套主题进行了零重叠、无白块的工业级全场景适配；
5. 构建终身学情画像与极客学术研学社区： 增加了 SVG 五维掌握度雷达图、目标院校备考规划方案，以及支持多账号深度互动、卡片一键分享的学术社区。
