### （1）项目详情及使用方式

#### 1. 项目详情
* **项目名称**：CSCOPE · 计算机微观仿真与 408 统考全真研学平台
* **立项定位**：“把看不见的计算过程，变成可以操作的实验”。平台专为计算机专业学生、全国 408 统考学子与体系结构极客打造，是集**“微观物理时钟级仿真沙盒”**、**“105 道历年真题做错一键唤醒实验验证”**、**“DeepSeek-R1 深度思维链伴学”**与**“终身学情掌握度画像”**于一体的现代化教育基础设施。
* **业务闭环**：
  $$\text{概念微观推演} \longrightarrow \text{统考全真评测} \longrightarrow \text{做错一键注入沙盒} \longrightarrow \text{AI 深度私教攻坚} \longrightarrow \text{学情雷达定向提分}$$

#### 2. 使用方式（极简快速上手）
* **第一步：居中大画幅门禁与主题选择**
  * 访问系统首页（默认 `http://127.0.0.1:5173/`），可于右上角在**曜石暗黑、赛博朋克、苍林护眼、纯净白昼**四套主题间自由切换；
* **第二步：安全鉴权登录 / 注册**
  * 点击居中主按钮 **`🚀 账号登录 · 验证进入实验室 →`** 进入登录专区，选择已有学者档案【小明同学】并输入密码 `123456`，或点击“新建学籍档案”输入考研目标院校注册；
* **第三步：25 门微观时钟仿真沙盒操作**
  * 进入实验大厅，点击任意实验（如 `CPU 流水线` 或 `Cache 映射`）。点击“单步打拍”逐步观察寄存器时序；拖动参数观测 RAW 数据冒险前递或 Cache 组相联对抗 100% 颠簸过程；
* **第四步：408 真题评测与错题靶向唤醒**
  * 进入真题评测中心，答错题目后，点击题目下方浮现的绿色按钮 **`立即启动仿真实验推演 →`**，系统自动将题目参数注入对应沙盒，单步推演破除认知盲区；
* **第五步：AI 私教与学情画像复盘**
  * 随时呼出 DeepSeek-R1 私教，展开深度思维链剖析疑难公式；在学情中心查看五维雷达图与针对目标高校的备考建议。

### （2）项目的核心亮点

1. **物理时钟级单步打拍与微观时序可见化**：
   * 彻底颠覆书本上抽象静态的流水线和状态图，将 CPU 五级流水线（IF/ID/EX/MEM/WB）的晶振打拍、RAW 冒险前递机制、停顿气泡插入以及 Cache 组相联映射中的块淘汰过程毫秒级全息呈现。
2. **首创“做错真题 ➔ 一键唤醒仿真沙盘”研学闭环**：
   * 收录 105 道 2009~2026 年统考真题。做错题目不再枯燥阅读文字解析，系统基于考点意图优先加权算法，在错题下方智能打通仿真传送门，题目参数一键灌入沙盒，用物理推演终结死记硬背。
3. **DeepSeek-R1 深度思维链 + 离线知识图谱双轨私教**：
   * 既能接入真实大模型展现完整的深度思考推理链（CoT），又内建了覆盖 408 核心考点的离线精编知识图谱，离线环境下同样提供秒级无损答疑。
4. **终身学情五维雷达画像与考研目标定制**：
   * 依托 SVG 动态多边形技术，动态追踪计组、OS、计网、算法、仿真五大维度的薄弱环节，针对学者设定的目标院校定制阶段学习时间配比。
5. **高健壮三级降级容灾设计（复现性极强）**：
   * 在线大模型 ➔ 本地预计算 JSON 矩阵 ➔ 纯前端本地数学沙盒。即使在完全断网、无外部 API 的纯裸机评审场景下，全套系统 100% 稳定运行。

### （3）AI 测试技术落地使用情况概述

在本项目全研发周期中，团队深度融合了现代化 **AI 赋能的软件测试与质量保证技术**，确保复杂时钟时序与并发逻辑的零缺陷交付：

1. **AI 驱动的时序仿真状态机一致性断言测试**：
   * 借助 AI 测试辅助工具，针对 CPU 五级流水线在不同指令序列组合下的冒险分支，自动生成了 120 组边界汇编测试用例，覆盖无冒险、EX前递、MEM前递、Load-Use停顿等全部边界条件，自动化断言校验周期数（CPI）计算的绝对精确性。
2. **408 题库与微观沙盒参数映射边界压力测试**：
   * 利用 AI 编写自动化映射测试脚本，对 105 道统考真题的参数向 25 门实验沙盒的注入接口进行全量回归测试，确保每一道计算题唤醒沙盒时，地址位宽拆解（Tag/Index/Offset）与安全序列矩阵无任何类型崩溃或 NaN 异常。
3. **AI 辅助的排版防御性组件安全审计**：
   * 在极客社区多账号测试中，利用 AI 模糊测试（Fuzz Testing）生成长达数百字符的特殊 URL、损坏图片链接与极端多字符昵称，成功排查出网络头像字符串横向溢出重叠的严重渲染缺陷，并驱动生成了通用的 `AvatarBadge` 异常捕获与降级容灾机制。
4. **全链路可复现性离线回归测试**：
   * 运用自动化测试脚本模拟“切断网络连接”、“清空环境变量”等极端环境，断言系统三级降级链路能否在 0 毫秒内无缝接管，杜绝任何未经捕获的 Promise 报错与白屏。
