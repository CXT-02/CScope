## 三、已完成且验证通过的部分（D0 ~ D3-4）

- **可降级设计**（保住复现性 25 分）：后端在线→预计算→示例数据 三级降级链，前端自动探测

## 五、产品升级与当前进度（2026-10-28）

用户已确认将项目从单一 Attention 工具升级为计算机知识可视化实验室。比赛版用三个模块证明平台扩展能力：

1. Transformer 注意力机制：保留原有真实模型、层/头切换、连线图和热力图。
2. Dijkstra 最短路径：可选择起点、逐步运行、查看距离松弛和路径树。

已完成平台化第一版：实验大厅、轻量状态导航、实验注册表和三个可运行实验均已落地，前端生产构建通过。

已完成平台化第二版：
- 三个实验均接入“预测 → 操作 → 观察 → 总结”主动学习循环，学习总结保存在浏览器本机。
- 使用哈希路由支持直接访问 `#/lab/attention`、`#/lab/dijkstra`、`#/lab/scheduling`。
- Attention 温度缩放已在真实、预计算、示例三级数据链中生效。
- 已用本机 Edge 无头模式完成首页和三个实验页的真实浏览器渲染验收。

已完成交互与视觉修正版：
- 修复后端离线时 Attention 始终显示固定 token/矩阵的问题；文本、Layer、Head、Temperature 现在都会驱动本地模拟权重变化。
- 后端模型加载失败时同样返回参数相关的动态模拟矩阵，不再返回均匀占位矩阵。
- Attention 连线改为曲线路径并加入平滑权重过渡，新增每个 token 的 Top-K 关系筛选，避免全矩阵连线过密。
