## 🎤 答辩评委高频提问 (FAQ) 预案（必背）：

### Q1：你们的仿真逻辑是真实计算还是纯动画播放？
> **回答要点**：
> “报告评委老师，我们的仿真**绝非预录动画，而是基于纯正的物理时钟状态机与数学模型驱动的真实交互仿真**。  
> 例如在 CPU 流水线中，学习者可以自由输入任意不同的汇编指令序列，系统每打拍一次，寄存器和流水段中的数值根据操作码和操作数实时计算更新；在 Cache 映射中，只要改变主存地址、组数或块大小，系统便实时进行二进制位运算并重新判断命中或缺失。所有的状态流转都由严谨的数学状态机实时驱动！”

### Q2：如果评审现场没有网，或者商业大模型 API 额度耗尽怎么办？
> **回答要点**：
> “我们专门针对竞赛严苛环境设计了**三级降级容灾架构**。  
> 第一级是在线大模型与 PyTorch 实时计算；第二级是本地预计算权重；第三级即使彻底拔掉网线，所有 25 门物理时钟仿真、105 道真题库测评、错题一键联动、学情雷达画像以及离线 408 知识图谱全部由前端本地沙盒独立驱动，**即使断网也能 100% 稳定运行，绝不发生白屏或功能中断**。”

### Q3：市面上已有不少刷题软件，CSCOPE 的最大核心差异化是什么？
> **回答要点**：
> “传统刷题平台与实验平台是**完全割裂的两个孤岛**：题库只给文字解析，实验平台只跑预设用例。  
> CSCOPE 的最大创新在于**首创了‘真题与微观仿真的动态联动引擎’**：当学生做错 2023 年统考 Cache 题目时，系统一键唤醒仿真沙盘并将该题参数直接导入，学生亲眼看到颠簸发生并手动改用组相联验证消除颠簸，从根本上攻克思维盲区，这是传统题库完全无法企及的深度。”
