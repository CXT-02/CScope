AI Collaboration · Case 01

“银行家算法”为什么被推荐成“二叉树遍历”？

Before

通用词抢先命中

回答正文中的“递归检查”触发了排在前面的二叉树实验，程序立即返回。

After

意图优先全局评分

提问专有词权重最高，遍历 25 个实验后选择最高分，并加入回归测试。

AI Collaboration · Case 02

长头像 URL 为什么会穿透评论输入框？

Before

URL 被当成纯文本

After

统一 AvatarBadge

图片语义渲染、加载失败降级、首字徽章与 CSS 容器防御。
